# 归潮湾 v44.2 · 全岛草毯与远坡红枫

桌面「深海灯塔—最新版」启动 v44.2。

- 内环步长 0.72 米，12 层壳。外环步长 1.44 米，8 层壳。北、西、南坡按现有地形和生境铺设草毯，保留裸岩、潮间带和设施间隙。
- 内外环共用交界采样，外环边缘三角接到内环中点，公共壳层高度一致。内环增加的壳层在接缝处渐隐。草毯分成 26 个内环区块和 40 个外环区块，独立剔除。中远景按屏幕投影只提交 3 层或 1 层网格。
- 按原生红枫的枝叶网格补种 10 棵外坡红枫。采样保护了 41 处木阶落点。
