# 归潮湾 v33 · 海岬植被与渔村生活

Windows 程序 `Builds/SeaLushV33/Guichao-SeaLushV33.exe`，桌面入口「深海灯塔—最新版」。

![主海湾与秋叶松林实机全景](preview.jpg)

![房屋接地、坡地植被与渔村陈设](02-lush-ground-and-village-life.jpg)

[水下伴生礁群特写](03-organic-reef-patch.jpg)

- 26 棵海风黑松和 18 棵枫树组成混交林。原枫叶贴图保留叶片形状，现有树冠分为绯红、丹橙、琥珀和绛紫四种秋色。
- 岸坡和林下布置 160 簇野花草、85 簇蕨丛与 42 组覆苔岩簇。三座房屋底部另有 33 处接地石和蕨草。地形顶点和碰撞体沿用 v32，平滑处理作用在陆上渲染法线。
- 晒网架、推车、篝火、围栏、岸滩小船分别为 4、4、2、14、3 处。陈设按可见地面、步道和现有构筑物避让，篝火有动态火焰和局部暖光。
- 六种水下生物重排为 38 组礁斑，共 189 株。每组有主株和三至五株伴生植物，按实测水深落根，保留桌珊瑚与海葵的辨识效果。

Unity 构建成功，十个 Blender 模型共 12572 个三角面，报告记录 1 项构建警告。最终通过 191 项运行检查和 20 项 Windows 键鼠检查。三张图片来自同一版独立程序的 1920×1080 可见窗口。

沿用 v30 界面、v32 建筑和既有存档路径。普通启动读入 19 项既有设施和 1 个已建展缸，隔离测试前后核对 5 份正式 JSON 存档。
